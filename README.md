# skyComply — design preview

The published build of the skyComply front end, for design review.

One source of truth: this is the app itself, not a separate set of mockups.
Auth is stubbed (no Azure AD B2C) and every `/api` call is answered by an
in-browser fixture shim, so there is no backend, no database and no real
tenant. All communities, residents and staff in the fixtures are invented.

Preview only. Not connected to any production system.
